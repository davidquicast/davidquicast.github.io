# Portfolio design

The current portfolio uses a compact profile sidebar, an image-led catalog and native overlay readers. It remains a static Jekyll site for GitHub Pages, with English visible and localization infrastructure retained.

- [Design system](readcv.md): composition, palette, type, navigation, media, motion and reading behavior.
- [Current verification](section-refinement.md): category composition, Research illustrations, compact connections and About.
- [Date and activity system](date-system.md): precise dates, verified project activity and ordering.
- [Academic integration](research-integration.md): profiles, coauthorship and cited-work distinctions.
- [Activity refresh contract](../project-activity.md): provider semantics, offline fallback and Docker refresh commands.
- [Reference inventory](readcv-references.md): all 44 read-only images and three editable Figma frames, with fidelity limits.
- [Editorial image record](editorial-images.md): shared direction, source provenance, dimensions and delivery budgets.
- [Research illustrations](research-images.md): four abstract-specific artworks and responsive image budgets.
- [Pretext architecture](../pretext.md): real components, preparation reuse, font handling and scoped lifecycle.
- [Tool and component provenance](../redesign-tools.md): pinned skills, MCP operations, versions and licenses.
- [Template capabilities](../template-capabilities.md): retained feature flags, scoped renderers and provider requirements.
- [CV source and previews](../cv.md): original PDF, deterministic pages, accessible text and update workflow.
- [Publication authoring](../publications.md): validated records, static research details and citation exports.

Private continuity, raw captures, traces, generated masters and earlier working notes stay under ignored `.local/` storage. They are excluded from Git and the published site.

The latest Research sizing, regenerated artwork and Blog cover restoration are recorded in [compact editorial audit](compact-editorial.md).
